# Slide Visual Hierarchy

Hierarchy = a deliberate eye-path. Build it from 6 levers. The canonical (web) framework lives in
`dev-uiux-design/references/visual-hierarchy.md`; this is the 16:9 static-slide adaptation.

**Rule: exactly one primary focal point per slide.**

## The 6 levers

1. **Size** — title ≥36pt and ≥2× body. Adjacent hierarchy levels differ ≥1.25× (L1:L2 ≥1.5×).
   Max 4 type levels per slide. Hero number/KPI can be 60-72pt.
2. **Weight** — title 700-800 / section labels 600 / body 400-500. Never signal hierarchy by weight alone.
3. **Color emphasis** — 3 text contrast levels max (primary / secondary / muted). Accent on **≤2
   elements per slide** — the focal object only. "If everything is accent, nothing is."
4. **Spacing** — whitespace IS hierarchy. Nesting: section gap > group gap > element gap. More space
   around an element = more important. Edge margin ≥1.27cm, inter-block gap ≥0.76cm.
5. **Position** — primary message at upper-left or optical center; supporting content lower/right;
   citations, notes, page numbers in fixed peripheral zones. F-pattern (text slides) / Z-pattern (hero).
6. **Density** — alternate dense and sparse slides; never two dense slides back-to-back (except an
   appendix). A sparse slide after the title = breathing room.

## Per-slide hierarchy checklist

- [ ] Exactly one focal point (squint test — what do you see first?).
- [ ] Title ≥2× body; ≤4 type levels.
- [ ] Accent applied to ≤2 elements.
- [ ] Reading path is obvious (F or Z), not a scatter.
- [ ] ≥20% negative space; gaps consistent.
- [ ] No two dense slides in a row.
