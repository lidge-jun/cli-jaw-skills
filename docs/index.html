The contract is intentionally boring.

One skill, one directory.

A skill starts with `SKILL.md`. Optional `references/`, `scripts/`, `templates/`, and `tests/` folders keep large supporting material out of the primary instruction file.

Line-limit drift is tracked.

Known long Office skills are explicitly tracked, and new unexpected `SKILL.md` line-limit drift fails validation.

Secrets stay out.

Skills should use placeholders and environment-variable names, not committed tokens or user credentials.

OfficeCLI sync is explicit.

The existing sync workflow copies OfficeCLI-derived materials into document skill families when triggered. Local documentation changes do not push or deploy by themselves.

Counts and docs are verified from disk.

The CI workflow runs focused Python regressions, validates the public skill count, tracks known long Office skills, and confirms README/Pages metadata before Pages upload.
