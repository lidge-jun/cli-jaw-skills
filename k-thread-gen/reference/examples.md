## 후킹 약한 예 vs 개선안

| 원본 (약한 훅)                       | 개선안                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------- |
| "올해 구글 딱 두번 샀어"             | "올해 구글 딱 두번 샀는데 수익률이 이렇게 됨"                           |
| "새로운 팀원이 생겼습니다"           | "신규 팀원 월급 0원인데 24시간 일함"                                    |
| "AI 덕분에 사업계획서 작성이 편해짐" | "사업계획서 통째로 AI가 써주는 시대인데 그대로 내는 사람이 이렇게 많음" |

## 범 카테고리 공통 패턴 요약

1. **줄바꿈 > 마침표**: 거의 모든 예시에서 마침표 대신 줄바꿈 사용
2. **한 줄 = 한 호흡**: 길어도 2줄을 넘기지 않음
3. **첫 문장이 전부**: 후킹 실패 = 전체 실패
4. **구체적 숫자**: "3억", "107개", "90%", "50%" — 추상적 표현 안 씀
5. **개인 경험 우선**: "~라고 합니다" 보다 "~했음", "~만들었음"
6. **억지로 안 늘림**: 1슬라이드로 될 거 5슬라이드로 안 만듦
7. **댓글 유도**: "댓글에 공유하겠습니다", "스친들 선택은?"
8. **링크는 짧게**: `site.com/path…` 형태로 축약
