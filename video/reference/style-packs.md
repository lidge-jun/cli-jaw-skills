# Style Packs

Style packs are starting directions for video aesthetics. They are not a
substitute for validation. Pick one or define a project-specific variant.

Each pack defines palette, typography, density, motion, layout, allowed assets,
banned cliches, and verification focus.

## premium-tech-briefing

Use for GeekNews, developer news, AI/framework explainers, product technology
briefings, and polished internal technical summaries.

- Palette: off-black, charcoal, zinc-950; chrome/cyan or cool high-contrast
  accent
- Typography: large CJK-safe headline, compact labels, mono evidence text
- Density: editorial, 1 primary claim per beat
- Motion: one hero motion, quiet secondary drift
- Layout: asymmetric newsroom/developer briefing, not dashboard cards
- Allowed assets: code snippets, browser chrome, small source footer, data
  labels, subtle grid/scanline
- Banned: AI purple blobs, generic glass cards, centered card stack, decorative
  assets without evidence value
- QA focus: headline readability, source footer legibility, restrained accent

## developer-console-explainer

Use for terminal, code, logs, build/test evidence, CLI workflows.

- Palette: graphite, terminal green/cyan/amber accents
- Typography: strong mono for evidence, clean sans for explanations
- Density: medium-high, but grouped by command/result
- Motion: type-on, line reveal, cursor/selection accents, subtle panel shifts
- Layout: console/evidence left, explanation right or top/bottom
- Allowed assets: terminal frames, command chips, diff snippets, status badges
- Banned: fake terminal noise, unreadable tiny code, excessive glow
- QA focus: code legibility and command/result hierarchy

## product-launch-kinetic-type

Use for launches, feature announcements, and short promotional explainers.

- Palette: brand base plus one sharp accent
- Typography: oversized display type, tight copy
- Density: low-medium
- Motion: kinetic type, scale, wipes, staggered phrase reveals
- Layout: full-frame text choreography, not card UI
- Allowed assets: product screenshots, logo, 1-2 texture layers
- Banned: too many claims per beat, generic gradient hero, stock-like b-roll
- QA focus: rhythm, timing, and final-frame layout

## data-newsroom

Use for benchmark, market, metrics, and trend videos.

- Palette: dark neutral or editorial light, one data accent plus muted secondary
- Typography: clear numeric hierarchy, tabular numbers
- Density: medium-high
- Motion: chart draw-on, counter, spotlight, annotation reveal
- Layout: chart or metric owns at least 70% of the frame
- Allowed assets: charts, axes, labels, source footer, callout line
- Banned: tiny chart in a card, unlabeled data, decorative chart junk
- QA focus: axis/label readability and source clarity

## quiet-enterprise-report

Use for conservative internal reports and executive summaries.

- Palette: neutral base, restrained blue/green accent, high contrast
- Typography: calm sans, strong hierarchy, minimal decorative type
- Density: medium
- Motion: fades, slight slides, measured reveals
- Layout: report-like but still full-frame, not a web dashboard screenshot
- Allowed assets: tables, metrics, process diagrams, short captions
- Banned: playful kinetic type, neon effects, excessive transitions
- QA focus: calm pacing and legibility

## math-algorithm-blackboard

Use for math, algorithm, or concept education.

- Palette: near-black, chalk/off-white, one accent for current step
- Typography: mono/math-friendly sans
- Density: progressive, one concept step per beat
- Motion: draw-on, highlight sweep, step reveal
- Layout: left proof/diagram, right explanation or sequential build
- Allowed assets: formulas, diagrams, pseudocode, arrows
- Banned: dumping full derivation at once, unreadable formulas
- QA focus: step order and formula readability

## Global Bans

- generic AI purple/blue blob backgrounds
- repeated glow-orb -> card -> text structure
- all-centered layouts for every beat
- emoji as visual system
- text clipping
- CJK orphan line fragments
- motion without narrative purpose
- unreadable code or charts
